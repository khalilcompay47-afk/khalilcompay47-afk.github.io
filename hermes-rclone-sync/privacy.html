Privacy Policy

Hermes Rclone Sync is a personal, locally operated Google Drive synchronization workflow. This notice explains how it uses Google account data. It is not a publicly offered application.

Data accessed

With the account owner's consent, Rclone requests Google Drive access in order to locate designated folders, list file names and metadata, check file contents, and create, download, update, or back up selected vault files. Google Drive's full-access OAuth scope may technically allow access to other files in the owner's Drive; the configured synchronization is intended for the owner's explicitly selected vault and backup folders.

Purpose and use

Google user data is used only to authenticate the owner's Drive account, synchronize chosen Obsidian Markdown files between the owner's Windows and Android devices, maintain conflict safeguards and optional backups, and troubleshoot failed sync attempts. Google user data is not used to train AI models, display advertisements, sell information, or develop advertising profiles. The site itself does not ask visitors to sign in.

Where data is stored

Selected synchronized files remain in the owner's Google Drive and device folders. Locally running Rclone stores Google OAuth access and refresh tokens in its configuration files on the owner's devices; these files should be kept private and out of the synchronized vault. Routine diagnostic logs may contain file paths, file names, status messages, and error details and are intended to remain on the owner's device. The website is a static information page and does not receive or store Drive files or OAuth tokens.

Sharing and third parties

No Google user data is sold or intentionally shared with unrelated third parties. Google processes Drive data as the service provider for the connected account. Rclone is open-source software used locally to communicate with Google's APIs. This website is hosted on GitHub Pages, which may process ordinary hosting information such as IP addresses under its own policies. There is no separate analytics, advertising, or user-data collection service configured for this website.

Security and retention

The workflow uses encrypted HTTPS connections to Google Drive and encrypted SSH for device administration where configured. It uses safety checks and local backups to reduce unwanted file changes. No method offers absolute security. Vault files and backups are retained in locations controlled by the owner until the owner removes them; OAuth credentials remain in local Rclone configuration until removed or revoked. This public website does not retain Google Drive content.

Owner controls and deletion

The owner may pause synchronization, delete local or Google Drive copies and backups, remove Rclone configuration credentials, or revoke the app's Google access at any time. Revoking Google access stops further authorized API calls but does not automatically erase previously synchronized files; delete those separately from the relevant device and Google Drive folders.

Google API Services User Data Policy

The workflow's use and transfer of information received from Google APIs follows the Google API Services User Data Policy, including its Limited Use requirements. Google data access is limited in practice to the owner-authorized sync purpose described above.

Changes and contact

This notice will be updated if the workflow's data use materially changes. For questions about the OAuth client, use the support email displayed on its Google authorization consent screen.
